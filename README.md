# Salem Mania!
salem mania is an independent, non-profit, literary publication. for the culture, by the culture. 
pitches open seasonally, all submissions will be peer-reviewed by the mania's network, and articles are chosen personally.
articles will be chosen strictly based on quality, culture, and the impact they will produce.
each salem mania network member is chosen and applications are open seasonally to work with salem mania. 
 
note: the mania's code is open source but the brand is not. all unauthorized users attempting to plagarize salem mania unlawfully are subject to persecution.
